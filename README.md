# Nova-Retail-Analytics
SQL analysis of Nova Retail Group's sales data. Exploring trends , tracking key performance indicators and generating data driven recommendations for business decision making.

# Project Overview
Nova Retail Group is a growing retail company operating across multiple regions in 
South Africa. The company sells consumer products through both physical stores and 
an online platform. The overview is to use SQL-driven analysis to identify the key factors affecting Nova Retail Group's revenue, profitability, customer retention, and product performance, and translate the findings into actionable business recommendations.

# Project Objectives
• Basic SQL queries (SELECT, WHERE, ORDER BY) 
• Aggregate functions (COUNT, SUM, AVG, MIN, MAX) 
• JOINs (INNER JOIN, LEFT JOIN, RIGHT JOIN) 
• GROUP BY and HAVING clauses 
• Subqueries and CTEs (Common Table Expressions) 
• Window functions (RANK, ROW_NUMBER, PARTITION BY) 
• Date functions and time-based analysis 
• Business intelligence and data interpretation
